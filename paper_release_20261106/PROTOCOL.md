# 实验协议（20261106 冻结版）

本文件固定本轮五配置的**训练、选模、评价与统计**口径。任何与本文件不一致的重跑结果都不能直接替换主表。

## 1. 数据

| 划分 | patch 数 | 用途 |
|---|---:|---|
| Train | 3799 | 训练与固定统计 |
| Valid | 245 | **唯一选模依据**（前景 IoU） |
| Test（历史） | 800 | 仅作历史反馈口径报告，见第 6 节 |

每个 patch 为 `[128,128,14]` HDF5：通道 0–11 为光谱，12 为坡度，13 为 DEM。标签为滑坡二值掩膜。

## 2. 归一化

### N0（四个 N0 配置使用）

1. 读取后转 `float32`，通道维提前为 `[14,H,W]`；
2. `nan/inf → 0`；
3. **逐 patch、逐 band** 用该 patch 自身 1%/99% 分位数裁剪（clip）；
4. 按 band 做 z-score（用该 patch 自身统计）；
5. 发生在数据增强与 128→256 放大**之前**。

### N2（仅 full14-S2-N2）

- 光谱 12 通道：**与 N0 完全相同**；
- 地形 2 通道（12 坡度和 13 DEM）：不再用 patch 自身统计，改用**固定的 Train 统计**（`configs/terrain_n2_stats.json`）：

| 通道 | 索引 | 均值 μ | 标准差 σ |
|---|---:|---:|---:|
| 坡度 | 12 | 1.2504486902559857 | 0.673978497358082 |
| DEM | 13 | 1.6496960918600854 | 1.0725785466274196 |

- 统计来源：**仅 Train**（3799 张，62,242,816 像素/通道），度量前同样先做逐 patch 1%/99% 裁剪；方差口径为**总体方差 ddof=0**，按像素计数汇总。Valid/Test 未参与。
- 注意：全局分位数由"每 patch 展平后每 64 像素取 1 个"的确定性抽样估计，min/max/mean/std 为全量精确值。
- 因此 N2 与 N0 的差异**只在两个地形通道的归一化统计**，不涉及光谱、不涉及网络结构。

## 3. 通道与初始化

- 物理 RGB 使用原始通道 **`[3,2,1]`**；历史 `rgb` 分支使用 `[0,1,2]` 的旧口径**不在本轮**，二者不可混称。
- full14 保持原始 0–13 顺序。预训练/源权重中 RGB 的三个核映射到位置 3/2/1，其余 11 个输入核**零初始化**。
- 只迁移 encoder；decoder 随机初始化（固定 seed）。

## 4. 尺度（S1 / S2）

- S1：原尺寸 128 训练与推理。
- S2：模型内部把输入放到 256 推理，UPerNet 输出 256 的父类 logits，再由包装器折回 128。**这是模型内部尺度，不是把数据重采样成 256 的新观测分辨率。**

## 5. 训练与选模

- 60 轮，seed ∈ {2026, 2027, 2028}；同名配置三 seed 独立训练。
- 选模指标：**Valid 前景 IoU**，取最大的一轮存为 best，`summary.json` 记录 best epoch。
- 评价：三视角 TTA —— 原图、水平翻转、垂直翻转；翻转回原方向后对 logits 求平均，再 argmax 得到二值预测。
- 指标：滑坡前景 IoU/F1/Precision/Recall、mIoU、OA、AP；混淆矩阵按全 dataset 像素池化（pooled），不是逐图平均。

## 6. 历史 Test 的可用性限制

历史 Test 已在此前的研究反馈中被反复使用，**不能**作为"从未参与开发"的独立确认集。本发布中 Test 数字只作历史口径报告，任何"Test 提升/下降"的措辞必须与第 7 节的区间一起读。

## 7. 统计口径

- 配对 patch bootstrap：B=5000，seed 20261105，以 patch 为可交换单位，**条件于固定检查点**；不含训练随机性、选模不确定性。
- 未校正空间自相关；未做多重比较校正；区间是"patch 可交换"假设下的**探索性**区间，不构成显著性证明。
- 四个对照点（见 `results/bootstrap_summary.csv`）：
  - C1：full14-S2 − RGB-S2（多通道主效应）
  - C2：full14-S2-N2 − full14-S2（地形归一化效应）
  - R1 / R2：同向参照
  - D = Test 效应 − Valid 效应（D = ΔTest − ΔValid，划分间方向一致性）
